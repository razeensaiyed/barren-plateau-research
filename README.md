# Barren Plateau Scaling in Variational Quantum Circuits

**Status: research in progress.** This repository is a working record, not a
released library. Notebooks are numbered in execution order; several contain
approaches later abandoned, retained deliberately so the reasoning is traceable.

Nine methodological questions remain open and are tracked in
`audit/discrepancy_parking_lot.md`. These include the fitting method behind the
published constants (P1), the absence of completed noise data (P8), and the lack
of an identified physical mechanism (P5).

- `notebooks/` — experiments in execution order
- `notebooks/history/` — crashed runs and intermediate saves, kept for provenance
- `data/` — result datasets
- `audit/` — per-notebook audit log and open-question tracker
